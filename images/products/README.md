# Product media

Upload product photographs and short product videos to this folder.

Use lowercase filenames without spaces, for example:

- `mly-dr-004-front.webp`
- `mly-dr-004-back.webp`
- `mly-dr-004-video.mp4`

Reference files from `js/products.js` using paths such as
`products/mly-dr-004-front.webp`.
