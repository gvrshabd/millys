How to manage the catalogue

  1. Use the stock menu beside a product for immediate availability changes.
  2. Choose Add product to create an unpublished draft.
  3. Complete English and Thai information, then save the draft.
  4. Upload and arrange photographs after the first draft save.
  5. Preview the customer view and publish only when everything is ready.
  6. Archive products that should disappear without deleting their history.

For backup and recovery instructions, see the owner management guide in the repository.

Grant or revoke administrator access

Administrator access is deliberately controlled in Cloudflare rather than from this website. This prevents an administrator session from quietly granting access to another person.

  1. Add or remove the exact email address in the Milly's Cloudflare Access Allow policy.
  2. Update the Worker's protected ADMIN_EMAILS value with the complete comma-separated list of approved addresses.
  3. Test the changed email in a private browser window. Keep the previous administrator signed in until the test succeeds.

Both controls must agree. Ask the technical maintainer to perform these steps; never send passwords, one-time codes or Cloudflare tokens.
